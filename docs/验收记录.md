## 当前产品边界

- 单视频整理采用程序去重和分类；大模型用于分段事实提取及跨视频行程/冲突识别。
- 上下文过长时行程编排会选择部分事实并显式提示；完整事实仍在章节与来源中，不丢弃原文。
- 数字和引用检查不能证明语义完全正确，仍需人工核实。
- 没有地理数据时不合并同名地点，不计算地图距离和最佳路线。
- 预算保守列出原文金额，缺少计量口径时不计算总价。
- 跨任务不共享媒体缓存；同一任务重试和版本调整复用持久化结果。
- macOS 本机已验证；其他操作系统未验收，Windows 文件锁需适配。
